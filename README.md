# Visual Creative Suite 🎨

Workstation digital profesional yang dirancang untuk mempercepat alur kerja desainer dan konten kreator melalui pengolahan gambar lokal berkinerja tinggi.

## 🚀 Fitur Unggulan

### 📸 Visual & Gambar (Tanpa AI)
- **Konverter Gambar Cerdas**: Konversi massal ke WebP, JPG, atau PNG dengan optimisasi kompresi instan.
- **Resizer Pro**: Ubah ukuran gambar untuk berbagai preset media sosial (Instagram, YouTube, TikTok) dengan fitur *Center-Crop*.
- **Filter Studio**: Editor foto lokal untuk menyesuaikan kecerahan, kontras, saturasi, dan filter artistik (Grayscale, Sepia).
- **Ekstrak Palet**: Identifikasi warna dominan dari gambar dan dapatkan kode HEX untuk referensi desain.
- **Smart Trim (Potong Cerdas)**: Penghapusan area kosong atau margin transparan secara otomatis menggunakan algoritma deteksi piksel.
- **Generator Mockup**: Ciptakan visual produk dengan bingkai browser dan latar belakang kustom yang elegan.

## 🛠️ Teknologi Utama
- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **UI & Styling**: [Tailwind CSS](https://tailwindcss.com/) & [ShadCN UI](https://ui.shadcn.com/)
- **Image Processing**: Canvas API & Browser-local processing
- **Icons**: Lucide React

## 🏁 Memulai Pengembangan

1. **Instalasi Dependensi**:
   ```bash
   npm install
   ```

2. **Jalankan Aplikasi**:
   ```bash
   npm run dev
   ```

## 🔐 Privasi & Keamanan
Aplikasi ini memprioritaskan privasi mutlak. Seluruh proses pengolahan gambar (Konversi, Resizing, Filtering, dan Trimming) dilakukan secara **lokal di browser Anda**. Tidak ada data yang dikirim ke server mana pun, memastikan aset Anda tetap aman di perangkat Anda.
