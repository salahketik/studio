# **App Name**: WebPGator

## Core Features:

- Multiple Image Upload: Accept multiple image uploads (drag and drop or file selection).
- Bulk Conversion to WebP: Client-side conversion of images to WebP format using browser-based tools. Uses browser-based tools to preserve detail while aggressively minimizing size.
- Progress Indicator: Display a progress bar during the conversion process.
- Download Options: Allow users to download converted images individually or as a single ZIP archive.
- AI-Assisted Compression: AI-powered tool which allows a user to choose an acceptable amount of information loss using a slider and/or by describing properties of the photo or desired end use; automatically optimizes WebP compression settings.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) for a calm and efficient feel.
- Background color: Very light gray (#F5F5F5) for a clean and modern look.
- Accent color: Teal (#008080) for call-to-action buttons and progress bars.
- Body and headline font: 'Inter', a sans-serif font, for clear and modern readability.
- Simple, intuitive icons to represent image formats and conversion status.
- Clean, drag-and-drop interface.
- Subtle animations on conversion, download, and hover effects to confirm interaction.
